# Prepared query and source specification

**Status:** 0.9.14, frozen

Release authorization is determined by `RELEASE_READINESS.json`; freezing these authorities alone does not authorize launch.

## Scope and dates

Search any mental function meeting the protocol's X→Y criteria. The fourteen supplementary families below are recall checks, not a whitelist of eligible functions. Citation discovery, all manuscript references, broad discovery anchors, and function-triggered searches supply the principal coverage. Do not restrict functions to those conventionally labelled cognitive. Apply no publication-date, language, peer-review, or publication-type filter. Preprints and later available versions are eligible; link versions of one work only when identity is established, and retain the exact version used. `publication_date_policy = unrestricted` and `publication_cutoff = null` mean deliberately no date cutoff. Each retrieval time and completed result snapshot is retained; this is not a claim that the databases or literature are static.

The narrower reading-evidence policy in `PROTOCOL.md` §12 does not alter discovery, query windows, stopping rules or scientific function-search activation. A supported whole-Y unaware capacity can still earn its existing search without a direct awareness nondifference test or strong E. Editorial suitability is assessed later from the same source records; it is not a new screening exclusion or query quota.

## Source roles and fallback policy

OpenAlex is primary for bibliographic discovery and backward/forward citation traversal. Europe PMC is required in parallel with OpenAlex for every blind and activated function query; it also supplies metadata, text links, and a citation fallback where the parent is covered. Crossref supplies DOI identity and publisher-deposited backward references. The published article or an identified repository/preprint reference list is the final backward fallback. There is no implicit forward-citation equivalent of Crossref or a reference list. No additional database is mandatory.

For each citation direction, use a successfully identified OpenAlex work and its graph first. If identity, coverage, or the direction's retrieval is unavailable, try Europe PMC for that same direction. For a still-unavailable backward direction, try Crossref's deposited reference list, then the parent article/repository reference list. Do not require an automatic citation union at every parent. Record each attempted source, identity match, reason for fallback, coverage limitation, and result encounter. A source that does not index the parent is unavailable, not an empty citation result. A successful covered source may legitimately return zero; missing/truncated/error responses cannot be recorded as zero or complete. If no source supplies the required direction, keep that obligation incomplete and report the missing coverage.

Complete every selected citation direction to source exhaustion, with no paper or page quota. OpenAlex uses the work's `referenced_works` for backward references and `/works?filter=cites:WORK_ID&per_page=100&cursor=*` for forward citations, following returned cursors. Europe PMC uses `/{source}/{id}/references` or `/{source}/{id}/citations`, 100 records per page, through the reported result count/exhaustion. Crossref uses `/works/{doi}` and its `reference` list. Preserve source ordering and identifiers from each completed page, deduplicate records, and log every rediscovery. Partial or inconsistent pagination stays incomplete; retain completed pages and explicitly log any required restart without erasing earlier encounters.

The mandatory OpenAlex and Europe PMC query windows cannot substitute for each other, nor be replaced by a web search. A failed required window remains pending while independent work continues. Retry a transient failed request at most three times per checkpoint, using server Retry-After when supplied and otherwise waits of 5 then 20 seconds. A longer service wait is recorded for later continuation rather than blocking independent work. Do not repeatedly retry a query/authentication error without resolving it. Resource limits never satisfy a scientific stopping condition.

## Supplementary blind queries

Run all fourteen prepared families only after the principal frontier is provisionally satisfied. Each source/family receives one ranked window, at most 40 returned records; screen every return. Across both sources the ceiling is 1,120 encounters. No second page or quota redistribution is permitted. The canonical strings below are generated by `tools/query_instruments.py`.

- OpenAlex: `https://api.openalex.org/works`; the documented `filter=title_and_abstract.search` form; `sort=relevance_score:desc`, `per_page=40`, `page=1`.
- Europe PMC: `https://www.ebi.ac.uk/europepmc/webservices/rest/search`; `query` as below, `format=json`, `resultType=core`, default relevance order, `pageSize=40`, `cursorMark=*`, `synonym=false`.

Use the service's returned order for ties, including a tie at the final slot. Record that order and hash it; do not widen the window, rerank, or choose a preferred tied record. Completed snapshots are immutable and reused on resume. For a failed/incomplete response, retain the attempt and explicitly retry the same parameters; do not combine partial responses into a new ranked window. Cross-window duplicate identities retain distinct encounter records but one logical-paper record. If the exact interface becomes unsupported, report the blocked window rather than silently switching fields or sources.

The historical QCAL4-LEARN rendering remains deliberately omitted and retired. QREV6-LEARN is a separately versioned coverage instrument, not a continuation of that snapshot.

## Coverage rationale and limits

These preparation choices cross-check the Cognitive Atlas distinction between mental concepts and tasks (https://cognitiveatlas.org/about) and the NIMH RDoC inventory of positive/negative valence, cognitive, social, arousal/regulatory and sensorimotor systems (https://www.nimh.nih.gov/research/research-funded-by-nimh/rdoc/constructs/rdoc-matrix). Neither inventory defines this review's eligibility or claims an exhaustive theory of consciousness. The inventory supplies candidate content X, candidate use Y and task vocabulary; terms can name either X or Y. The PDF assessment establishes the actual relationship.

| Coverage cell | Candidate contents / uses to inspect | Task vocabulary examples |
|---|---|---|
| Attention / action | competing stimuli, goals, action rules | capture, inhibition, response selection |
| Perception / memory / language | objects, events, retained content, words | integration, adaptation, updating, retrieval, semantic priming |
| Metacognition | decisions, confidence, errors | sensitivity, monitoring, control |
| Learning | regularities, outcomes, stimulus contingencies | conditioning, sequence/statistical learning |
| Affect / social | emotional content, others' states | appraisal, regulation, empathy, inference |
| Bodily | internal signals, bodily ownership, agency | interoception, autonomic/homeostatic regulation |
| Pain / aversion | nociceptive and unpleasant content | analgesia, nociception, aversive processing |
| Pleasure / motivation | pleasant content, reward, incentive value | liking, wanting, effort allocation |
| Open | unfamiliar X or Y | awareness terms without a function restriction |

Separate pain, hedonic and motivation windows prevent these domains competing for one affect quota. All revised windows use the same broader awareness vocabulary. This can admit irrelevant awareness/visible-light records; individual semantic screening remains necessary. Broader coverage is a prospective design choice, not a measured recall improvement. The exact new queries have not yet received a live source diagnostic.

For each window preserve service total hits, returned count, result-set hash and whether the ranked cap truncated the result set. The 40-record blind and 50-record earned-Y limits are bounded recall checks, not saturation claims. The later small test will measure duplicate fraction, clear off-topic fraction, retained candidates and truncation. Those observations may motivate a separately versioned partition/expansion before the large run; they do not authorize automatic widening, quota transfer or query substitution inside this package. Citation recursion and unfamiliar earned Ys remain available under unchanged gates.

## QDYN001 — Function-triggered expansion

Activate once per newly normalized Y only after a comparable awareness contrast or supported supplementary capacity meets PROTOCOL §9.4. Any mental function may activate this route; membership in a blind family is unnecessary. Record the trigger comparison, exact Y, normalization decision, source, rendered query, and every term's provenance.

The lexical universe contains the canonical Y; direct morphology/grammar/spelling/hyphenation variants; terminology explicitly used for the same function in the qualifying source; and documented same-function external terminology with source pointer and identity rationale. No broader parent vocabulary is registered for this version, so the optional immediate-parent input must be omitted. Do not invent a frozen parent identifier or add neighboring functions or unrestricted synonyms. This avoids an extra function taxonomy.

Use both sources and the same fields/sort/snapshot rules as the blind lane, with one initial window of at most 50 records per source. Screen every returned record; no second page or quota redistribution. Both screen-in and screen-uncertain records receive full-text attempts. The same normalized Y never retriggers a completed source window. Only a genuinely new independently qualifying Y may recurse.
