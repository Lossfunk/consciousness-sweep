# Manual review guide for the planned Methods

The automated crosswalk verifies structure, not semantic equivalence. Review the package in four passes.

## Pass 1: scientific coherence

Read `METHODS.md` alone. Ask whether a researcher unfamiliar with the repository could reproduce what enters the sweep, how comparisons are formed, what each inference means, and when the search stops. Flag any passage that sounds outcome-driven or treats a draft value as registered.

## Pass 2: scientific fidelity

Read `METHODS.md` beside `PROTOCOL.md`. Check that simplification has not changed eligibility, A/E/F, result classification, statistics, Meyen, evidence transfer, discovery, or stopping rules.

## Pass 3: execution and reproducibility fidelity

Read `METHODS.md` beside `AGENTS.md`. Check record ownership, continuous writes, append-first revision, locked IDs, immutable snapshots, start/resume behavior, run isolation, validation checkpoints, and completion.

## Pass 4: unresolved items

Inspect `docs/methods_crosswalk.yaml` and `docs/documentation_issues.md`. Resolve the genuine pre-freeze decisions in the authorities/configuration, rerun the validator in freeze-time mode, and confirm that no unresolved crosswalk entries remain before registration.

## Highest-risk concepts

- [ ] X and Y are neither too broad nor destructively atomized.
- [ ] Factorial structure follows operational functional identity, with a focal comparison before components.
- [ ] A distinguishes procedure, reported result, evidential support, objective-test informativeness, and transfer.
- [ ] E-diagnostic states a same-Y competing account/prediction/violation and audits only anchored task-state alternatives.
- [ ] Every borrowed premise uses a direct, non-transitive, status-derived evidence bundle.
- [ ] An unaware-capacity claim exactly matches the whole focal functional Y; E is not its gate.
- [ ] No-detectable difference is not described as equivalence; positive null evidence uses a stated region.
- [ ] Search stopping includes principal-first/blind-last order, mandatory windows, immutable snapshots, and reopened frontiers.
- [ ] Independent runs share only static frozen inputs; adjudication preserves original judgments and is not majority voting.
